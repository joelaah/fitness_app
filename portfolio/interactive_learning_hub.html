LAB 6 • DATABASE INTERNALS

Supabase match_jobs() Vector RPC & <=> Operator

Look at the exact SQL stored procedure executed by JOB SeArCh in Supabase. Understand why the <=> cosine distance operator combined with HNSW cuts query latency from 850ms down to 8ms! 

-- 1. HNSW Index on 768-dim Vectors
CREATE INDEX ON jobs USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64);

-- 2. Stored Procedure (RPC) executed by Flutter via PostgREST
CREATE OR REPLACE FUNCTION match_jobs(query_embedding vector(768), match_threshold float, match_count int)
RETURNS TABLE (id uuid, title text, similarity float) AS $$
  SELECT id, title, 1 - (jobs.embedding <=> query_embedding) AS similarity
  FROM jobs
  WHERE 1 - (jobs.embedding <=> query_embedding) > match_threshold
  ORDER BY jobs.embedding <=> query_embedding
  LIMIT match_count;
$$ LANGUAGE sql STABLE;

What Happens When You Click A Button?

Watch the exact packet lifecycle from your finger on the screen down to the PostgreSQL disk blocks:

1. UI Event: Flutter triggers async BLoC event; freezes mutation state.
2. DNS Query: UDP port 53 resolves domain to IP in <15ms.
3. TCP & TLS 1.3: 3-way handshake + elliptic curve Diffie-Hellman key exchange.
4. HTTP Payload: POST request serialized into JSON byte stream.
5. FastAPI Async: Event loop dispatches request to non-blocking coroutine worker.
6. PostgreSQL WAL: Appends transaction to Write-Ahead Log on disk before memory commit.
